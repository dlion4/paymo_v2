Drop this into your page

<script src="https://js.paymo.co.ke/v1/checkout.js"></script> <button id="pay">Pay KES 1,240</button> <script> const checkout = PayMo.Checkout("pk_live_kilimani_cafe_x88", { amount: 1240, currency: "KES", order_ref: "KC-8829", onSuccess: (txn) => window.location = "/thanks?t=" + txn.id, }); document.getElementById("pay").onclick = () => checkout.open(); </script>
Use your publishable key (starts with pk_) on the browser. Never expose secret keys (sk_) on the client.
