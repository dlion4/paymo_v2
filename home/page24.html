Clause 2 · Authentication & Keys

Your keys. Your responsibility.

Secret key confidentiality
Never expose sk_live_ keys in client code, repos, or logs.
Key rotation
Rotate keys every 90 days. Compromised keys must be revoked within 24 hours.
Webhook signatures
Verify every webhook with HMAC-SHA256 before processing.
IP allowlisting
Restrict live keys to known server IPs in the dashboard.
verify-webhook.js 
const sig = req.headers['x-paymo-signature'];
const expected = crypto
  .createHmac('sha256', WEBHOOK_SECRET)
  .update(req.rawBody)
  .digest('hex');

if (sig !== expected) {
  return res.status(401).end();
}

Clause 6 · Versioning & Deprecation

Stable APIs. Predictable changes.

Date-based versioning

Pin a version with the X-Paymo-Version header (e.g. 2026-01-15). Your integration won't break from new releases.

12-month deprecation notice

Breaking changes get a minimum 12-month sunset window with migration guides and email notices.

Backward-compatible additions

New fields, endpoints, and optional params are added without a version bump.
