Authentication & Security

Multi-layer security. Fortress-grade by default.

API Keys

Publishable and secret keys with scoped permissions. Rotate, revoke, and scope per use-case from the dashboard.

OAuth2 · JWT

Full OAuth2 and JWT flows for user-scoped access on behalf of your customers. Refresh tokens keep sessions secure.

IP Whitelisting

Restrict your API keys to specific IP ranges and CIDR blocks. Any request outside your whitelist is rejected instantly.

HMAC Signatures

All webhooks signed with HMAC-SHA256 with a per-account signing secret. Replay-attacks are structurally impossible.

Rate Limiting

Starter: 1,000 req/min · Growth: 10,000 req/min · Scale / Enterprise: custom. Rate-limit headers inform your integration about current usage.

Idempotency Keys

All mutating endpoints support idempotency keys so retrying from client code is safe — no double-charging, no accidental double-payouts.
