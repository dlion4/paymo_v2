Authentication & Security

API keys. OAuth2. JWT. IP whitelisting. HMAC signatures. Pick your preferred mix.

API Keys

Publishable + secret key pairs. Rotatable, scoped, and granular. Sandbox, test, and live environments in one dashboard.

OAuth2

OAuth 2.0 authorization_code flow for apps that need delegated access to customer resources. Refresh token support, device flow support coming.

JWT

Short-lived JSON Web Tokens for client-side operations. Publicly-verifiable signatures, short TTL, scoped per-operation.

IP Whitelisting

Lock API keys to specific IP ranges. Per-key configuration, instant propagation to edge, automatic alerts on suspicious activity.

HMAC Signatures

Every webhook payload is signed with SHA-256 HMAC. Verify on your end to ensure Paymo — and only Paymo — sent it.

Role-Based Access

Admin, developer, finance, support, and viewer roles. Custom role definition coming. Audit every action to an immutable log.
